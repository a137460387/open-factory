## 2. Rust 依赖安全

### 2.1 已知 CVE

| CVE | 严重度 | 涉及 crate | 状态 |
|-----|--------|-----------|------|
| RUSTSEC-2026-0194 | HIGH (CVSS 7.5) | quick-xml 0.39.4 | 待确认是否仍存在 |
| RUSTSEC-2026-0195 | HIGH (CVSS 7.5) | quick-xml 0.39.4 | 待确认是否仍存在 |

**依赖链** (v4.12.0 数据，需更新):
```
tauri → tauri-utils → plist → quick-xml
```

**实际风险评估**: quick-xml 通过 plist 仅解析 macOS property list 文件，来源为本地系统文件，非网络不可信输入，实际不可利用。

### 2.2 建议

1. 在 CI 中运行 `cargo audit` 获取最新 CVE 状态
2. 定期检查 `cargo update` 是否可安全升级依赖

## 6. 关键发现与建议

### HIGH

1. **Rust CVE 扫描缺失** — `cargo audit` 未执行。quick-xml CVE (RUSTSEC-2026-0194/0195) 状态未知。
   - 建议: CI 中添加 `cargo audit` 步骤

### MEDIUM

2. **Node 安全扫描缺失** — 未运行 `npm audit` 或等效工具。
   - 建议: CI 中添加 `bun pm audit` 或 `npm audit --production`

3. **esbuild override >=0.28.1** — 约束为下限而非精确版本，存在引入不兼容版本风险
   - 建议: 考虑使用 `^0.28.1` 或定期验证 override 版本兼容性

### LOW

4. **bun.lock 格式** — 使用 Bun 专有 lockfile 格式（非 npm/pnpm/yarn 通用）。如果团队有成员使用其他包管理器，可能导致 lockfile 冲突。
   - 建议: 在 CONTRIBUTING.md 中明确要求使用 bun
