## 3. Tauri IPC 安全

### 3.1 Bridge 穿透发现

以下 6 处代码直接 import `@tauri-apps/api`，绕过了 `tauri-bridge.ts` 封装：

| # | 文件 | 行号 | import 内容 | 风险 |
|---|------|------|-------------|------|
| 1 | `apps/desktop/src/hooks/useGpuDetect.ts` | 2 | `invoke` from `@tauri-apps/api/core` | **HIGH** |
| 2 | `apps/desktop/src/hooks/useModelManager.ts` | 2-3 | `invoke` + `listen` from `@tauri-apps/api` | **HIGH** |
| 3 | `apps/desktop/src/hooks/useVideoGeneration.ts` | 2-3 | `invoke` + `listen` from `@tauri-apps/api` | **HIGH** |
| 4 | `apps/desktop/src/video-gen/video-gen-runner.ts` | 1-2 | `invoke` + `listen` + `UnlistenFn` from `@tauri-apps/api` | **HIGH** |

**违反规则**: AGENTS.md 规则14 — "All Tauri invoke/listen/dialog/shell calls from frontend business code must go through apps/desktop/src/lib/tauri-bridge.ts."

**影响**: 这些是 v4.60+ 引入的 LTX-Video AI 生成功能，未遵循 bridge 模式。导致：
- 无法在 mock 环境中测试这些模块
- 类型安全性无法通过 bridge 层的 TypeScript 类型约束保障
- 与现有 bridge 架构不一致

### 3.2 Tauri 命令注册审计

## 7. 关键发现与建议

### HIGH

1. **Bridge 穿透** — 4 个文件直接 import `@tauri-apps/api`（useGpuDetect, useModelManager, useVideoGeneration, video-gen-runner）。应将 invoke/listen 调用迁移至 `tauri-bridge.ts`。
   - 影响: 违反 AGENTS.md 规则14，无法 mock 测试，类型安全性降低

### MEDIUM

2. **依赖 CVE 扫描缺失** — 本次审计无法运行 `cargo audit`（环境无 Rust 工具链）。已知 quick-xml CVE (RUSTSEC-2026-0194/0195) 状态待确认。建议在 CI 中集成 `cargo audit`。

3. **文件系统命令授权检查分散** — `commands/files.rs` 中的 15 个命令的路径验证逻辑分布在 `path_validator` 和各自命令中，建议集中审计。

### LOW

4. **creator-dashboard** 和 **cloud-sync** 包含网络功能，应从核心编辑器包明确分离文档说明。
