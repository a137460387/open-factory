# open-factory AGENTS.md 重写计划

## 目标
参考 claude-code 的 AGENTS.md 结构，为 open-factory 项目完全重写一份 AGENTS.md 文档。

## 文档结构设计

### 1. 通用约定
- 语言要求：所有用户面向输出使用简体中文
- 本地优先原则：禁止遥测、登录、云服务

### 2. 运行背景与核心约束
- **项目定位**：本地优先的桌面视频编辑器
- **技术栈**：
  - 前端：React 19 + TypeScript 5.8+ + Vite 6.4
  - 桌面：Tauri 2 + Rust
  - 状态管理：Zustand 5
  - 包管理：Bun 1.3.14
  - 测试：Vitest + Playwright
- **架构约束**：
  - Monorepo 结构（apps/* + packages/*）
  - editor-core 必须保持纯 TypeScript，不依赖 Tauri
  - Timeline 变更必须通过命令对象
  - Tauri 调用必须通过 tauri-bridge.ts
  - 媒体预览必须使用 convertFileSrc

### 3. 核心架构约束（新增，参考 claude-code 的 provider-neutral 风格）
- **本地优先判定标准**：
  - 禁止在代码中硬编码云服务端点
  - 禁止添加用户登录/注册功能
  - 禁止添加遥测数据上报
  - 所有数据处理必须在本地完成
- **Timeline 命令对象约束**：
  - 所有 Timeline 修改必须通过命令对象执行
  - 禁止直接调用 Zustand setter 修改 timeline clips/tracks
  - 命令对象必须支持撤销/重做
- **Tauri Bridge 约束**：
  - 所有 Tauri invoke/listen/dialog/shell 调用必须通过 tauri-bridge.ts
  - 新增 Tauri 命令必须在 lib.rs 注册
  - FFmpeg 执行必须使用参数数组，禁止 shell 字符串

### 4. 开发流程默认策略（新增，参考 claude-code）
- **验证流程**：
  - 任何实现任务完成后必须通过 `bun run typecheck` 和 `bun run build`
  - editor-core 包必须保持 80% 以上覆盖率
  - 修改 ffmpeg-builder.ts 必须有对应测试
- **测试策略**：
  - 核心时间线算法必须有 Vitest 覆盖
  - 项目 schema 修改必须有迁移测试
  - 导出预设变更必须反映在测试中
- **构建要求**：
  - 禁止伪造成功的导出、测试或构建
  - 大文件处理必须异步执行，不阻塞 UI

### 5. 仓库安全边界（新增，参考 claude-code）
- **文件修改限制**：
  - 禁止修改 package.json/package-lock.json（除非明确需要）
  - 禁止全仓 format/lint --fix
  - 新增依赖需要明确说明理由
- **提交规范**：
  - 遵循 Conventional Commits
  - 安全相关变更必须单独提交
  - 每次 push 需要单独授权
- **PR 流程**：
  - PR 范围必须聚焦
  - 必须包含验证结果
  - 必须保持 data-testid 覆盖

### 6. 特定模块约束（整合现有规则）
- **媒体处理**：
  - 本地预览使用 convertFileSrc
  - 代理媒体仅用于预览，导出必须使用原始源
  - 后台媒体作业必须顺序执行或显式限流
- **导出系统**：
  - 导出队列必须保持每任务状态可见
  - 取消操作必须连接到 cancel_export
  - 预设变更必须有测试覆盖
- **缓存系统**：
  - 缓存键规则变更必须更新测试
  - Relink 评分变更必须更新测试

## 实施步骤

1. 创建新的 AGENTS.md 文件
2. 按上述结构组织内容
3. 整合现有规则，补充缺失部分
4. 运行 typecheck 和 build 验证
5. 提交更改
